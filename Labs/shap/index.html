Why does the baseline start at 30%?

We use four equally weighted reference customers. The fixed classifier predicts 10%, 30%, 10% and 70% for them. Their average prediction is 30%.

The baseline is an average prediction, not the proportion of customers who actually left. These fictional rows and model outputs are chosen for teaching.

How does SHAP divide the difference between the features?

A feature can add a different amount depending on which other feature is already supplied. For two features, SHAP averages over two possible orders.

“Complaints supplied” means keep this customer’s complaints value and fill tenure from each reference row, then average the predictions. Supplying tenure works the same way. The fitted classifier stays fixed throughout.

SHAP: SHapley Additive exPlanations. Contributions describe this model and reference group. They do not establish the causal effect of changing customer behaviour. This lab calculates exact two-feature Shapley values from its declared model and reference rows.
