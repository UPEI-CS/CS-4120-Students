Watch a genetic algorithm, one operation at a time

Follow one generation slowly. See which genes come from each parent and exactly what mutation changes.

First learn the mechanism with a simple problem: find a six-bit string containing as many 1s as possible. Fitness is the number of 1s. This toy problem makes every operation visible; it does not train a model.

Population

Current operation

Survival keeps four candidates from the parents and child. Equal fitness is resolved by their existing order. This simple demonstration uses one child per generation and always flips one bit.

How does this become model search?

Replace the bits with choices such as selected features, model family and hyperparameters. Replace counting 1s with fitting and validating the pipeline. Crossover combines choices; mutation changes a choice. A child must be evaluated before its quality is known. With five-fold CV, one new pipeline evaluation requires five fits.

The toy problem has a known optimum of 6. Real model search generally does not know the best possible validation score in advance. Evolutionary search is not guaranteed to outperform random search.
