This is a synthetic teaching dataset. Recency represents time since last use. Inactivity duplicates recency here. Complaints represents customer complaints. Tenure means how long someone has been a customer. Noise is an artificial random control. All five values are simulated standardised values, not days, counts or months.

Precision: among customers predicted to leave, how many actually leave? Recall: among customers who leave, how many did the model identify? A candidate must reach 70% recall before we compare precision.

What happens when I click Evaluate?

Each score is precomputed from three common stratified CV folds on 900 development cases. The browser reveals the result, so this lab needs no Python installation. Every candidate follows the same evaluation rules. Precision and recall are means of the three fold scores. The prediction threshold is 0.5.

The search rules, in plain language

Start with four distinct random candidates. For each child, choose two parents using two-candidate tournaments. Prefer an eligible candidate over an ineligible one. Among eligible candidates prefer higher precision. If neither is eligible, prefer higher recall.

Take the first one or two configuration choices from parent A and the remaining choices from parent B. With probability 0.7, mutate one choice to another allowed value. Evaluate four children. Keep the best four distinct candidates from parents and children. This is a small teaching genetic algorithm, not TPOT.

Random search starts with the same four candidates, then samples four candidates with replacement per round. It also retains the best four distinct candidates seen. Both have a budget of 36 proposals, including the initial four. Revisited candidates reuse their saved score. Compare unique evaluations as well as proposals.

All scores are precomputed and fixed. Changing the search seed changes the search, not the dataset, CV folds or tree fitting seed. This tiny space could be evaluated exhaustively. The animation illustrates a mechanism, not evidence that evolutionary search is faster or better.
