# Challenge 1: When a Straight Line Is Not Enough

**How can we choose a model that captures the pattern in the data without simply choosing the most complicated model?**

**This is group work.**

**You need:** about 75 minutes, a Google account for Colab, an AI partner, and basic familiarity with Python and linear regression. No local installation is needed in Colab.

## Start here

1. **[Open the starter notebook in Colab](https://colab.research.google.com/github/UPEI-CS/CS-4120-Students/blob/main/challenges/challenge-01/challenge-01-starter.ipynb)** and save a copy to your Drive.
2. Work through its eight checkpoints in order, writing and running your group's experimental code. Use the AI partner and snippets for syntax support; make and explain the modelling decisions together. Use the **[PDF instructions](challenge-01-instructions.pdf)** beside the notebook.
3. Need a file or a quick example? **[Download the dataset](data/challenge-01-data.csv)** · **[Code snippets](resources/code-snippets.md)** · **[View the notebook here](challenge-01-starter.ipynb)**
